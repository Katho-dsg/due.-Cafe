# due. — Café de especialidad

Landing page / tienda para **due.**, una marca de café de especialidad que trabaja con lotes limitados de 100 bolsas numeradas.

Sitio estático sin dependencias: abre `index.html` en el navegador.

- `index.html` — landing actual (hero con el empaque flotante, lotes, experiencia, club)
- `css/due.css` — diseño: #161D10 + #799733 con crema/blanco; League Spartan, Montserrat y Cormorant Garamond
- `js/due.js` — selector de lote del hero, bolsa simulada, cuenta atrás, formulario del club y animaciones
- `assets/landing/` — empaque de due. recortado (PNG transparente) y fondo desenfocado del hero
- `version-a.html`, `version-b.html`, `version-anterior.html` — propuestas anteriores

Los datos de lotes, precios y stock son de ejemplo y deben sustituirse antes de publicar.
