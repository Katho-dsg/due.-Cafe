# due. — Café de especialidad

Landing page / tienda para **due.**, una marca de café de especialidad que trabaja con lotes limitados de 100 bolsas numeradas.

Sitio estático sin dependencias: abre `index.html` en el navegador.

- `index.html` — estructura y contenido
- `styles.css` — diseño (paleta verde oliva, crema y latón)
- `script.js` — carrito, stock del lote, configurador de regalo, cuenta atrás y animaciones
- `assets/` — logotipo en versión oliva y crema (PNG transparente)
